# Poké Lids 2026 GitHub Sync

功能：
- GitHub Pages 網頁
- 每 5 分鐘由 GitHub Actions 檢查最新 Poké Lids
- 以縣／市分組
- 日本互動地圖：縣／市標記 → 縣市點位 → 點位 Popup
- FavoriteLists / iTools 相容 JSON 匯出
- 跨電腦共享 History（新增、移除、修改）

啟用：
1. 將本資料夾內容上傳到 GitHub repository。
2. Repository → Settings → Pages → Source 選 GitHub Actions。
3. Actions → Sync Poké Lids → Run workflow 可手動立即同步。
4. GitHub Actions 會每 5 分鐘檢查一次。
